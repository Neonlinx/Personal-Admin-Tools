# Windows Network Tools

- `Network-Toolbox.bat` provides interactive diagnostics and logging. Some operations require elevation.
- `Add-LMHOSTS-Mapping.bat` modifies the system LMHOSTS file and therefore requires Administrator privileges.
- `Refresh-NetBIOS-And-Open-SMB-Host.bat` refreshes NetBIOS caches, tests reachability and opens an SMB host path.

Generated logs under the local `logs/` subfolder are ignored by Git.
